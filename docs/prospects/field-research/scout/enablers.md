# Scout lane: timing & enablers

Scouted 2026-10-21 by a scout subagent.

## (a) Agent Skills format and the open standard

- **ENB-01** [grounded] Anthropic introduced Agent Skills on October 16, 2025, as folders of instructions, scripts and resources that Claude loads when a task calls for them, across claude.ai, Claude Code, the API and the Agent SDK; an update dated December 18, 2025 added organization-wide skill management, a partner skills directory, and publication of the format as an open standard at agentskills.io. — [Introducing Agent Skills](https://claude.com/blog/skills), accessed 2026-10-21.
- **ENB-02** [grounded] The open specification requires only a `SKILL.md` with `name` (up to 64 lowercase characters and hyphens, matching the folder name) and `description` (up to 1,024 characters); the only optional fields are `license`, `compatibility`, `metadata` and an experimental `allowed-tools`, and it recommends keeping `SKILL.md` under 500 lines with references one level deep. — [Agent Skills specification](https://agentskills.io/specification), accessed 2026-10-21.
- **ENB-03** [absence] No source found placing the Agent Skills specification under a neutral foundation, or naming its maintainers or a formal governance model; the repository says only that Anthropic developed it and that it is open to contributions, and it has no tagged releases. — Searched the agentskills.io overview, specification and llms.txt index, the [agentskills/agentskills README](https://github.com/agentskills/agentskills), and web search for "Agent Skills specification Agentic AI Foundation AAIF Linux Foundation skills standard governance 2026", 2026-10-21. (The agentskills.io client showcase page rendered empty, so its adopter list was not read.)

## (a) Adoption by other vendors

- **ENB-04** [grounded] OpenAI's changelog dates "Agent skills in Codex" to December 19, 2025, for the Codex CLI and IDE extensions, and says the format follows the agentskills.io specification; plugins that bundle skills, app integrations and MCP configuration followed on March 25, 2026. — [ChatGPT & Codex changelog](https://learn.chatgpt.com/docs/changelog), accessed 2026-10-21.
- **ENB-05** [grounded] OpenAI's current docs say standalone skills run in the ChatGPT desktop app, Codex CLI and Codex IDE extension, and skills bundled in plugins also run in ChatGPT on web, desktop and mobile; Codex reads skills from `.agents/skills` in the repo and `~/.agents/skills` for the user, with an optional `agents/openai.yaml` for OpenAI-specific metadata. — [Build skills](https://learn.chatgpt.com/docs/build-skills), accessed 2026-10-21.
- **ENB-06** [grounded] GitHub announced Agent Skills on December 18, 2025, for the Copilot coding agent, Copilot CLI and VS Code Insiders agent mode, and said Copilot automatically picks up skills already stored in a repository's `.claude/skills`. — [GitHub Copilot now supports Agent Skills](https://github.blog/changelog/2025-12-18-github-copilot-now-supports-agent-skills/), accessed 2026-10-21.
- **ENB-07** [grounded] Google announced skills for the Gemini app and Workspace on September 30, 2026, built on an "open, Markdown-native SKILL.md standard", with the Gemini app rollout starting October 13, 2026; Gems move to the Settings panel on November 17, 2026, and for business accounts stop working no sooner than March 1, 2027. — [Introducing skills in the Gemini app and Workspace](https://workspaceupdates.googleblog.com/2026/09/skills-gemini-app-workspace.html), accessed 2026-10-21.

## (a) Installing and running skills in claude.ai

- **ENB-08** [grounded] Anthropic's own pages disagree on the Free plan: the help center lists skills on Free, Pro, Max, Team and Enterprise, while the claude.com docs list only Pro, Max, Team and Enterprise; both say "Code execution and file creation" must be turned on, and custom skills are uploaded as a ZIP from Customize > Skills. — [Using skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude); [Skills overview](https://claude.com/docs/skills/overview), accessed 2026-10-21.
- **ENB-09** [grounded] On Team and Enterprise, owners can provision skills to every member, members can share a skill view-only with specific people (or groups on Enterprise) or publish it to an organization library that owners can gate behind review, and Enterprise can scan third-party skills before they run. — [Using skills in Claude](https://support.claude.com/en/articles/12512180-using-skills-in-claude), accessed 2026-10-21.
- **ENB-10** [grounded] The Claude Platform docs page on Agent Skills states the opposite for claude.ai: custom skills are individual to each user, cannot be centrally managed by admins, and do not sync across claude.ai, the API and Claude Code. — [Agent Skills (Claude Platform docs)](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview), accessed 2026-10-21.
- **ENB-11** [grounded] Claude Code accepts extra frontmatter (invocation control, `context: fork` subagent execution, hooks, arguments), but claude.ai skill uploads and the Skills API accept only the six spec fields and fail with a hard error on any other key. — [Extend Claude with skills](https://code.claude.com/docs/en/skills), accessed 2026-10-21.

## (a) Plugins and marketplaces

- **ENB-12** [grounded] Claude Code plugins entered public beta on October 9, 2025, bundling slash commands, subagents, MCP servers and hooks, installable from any git repository or URL that serves a `.claude-plugin/marketplace.json` via `/plugin marketplace add`. — [Customize Claude Code with plugins](https://claude.com/blog/claude-code-plugins), accessed 2026-10-21.
- **ENB-13** [grounded] claude.ai now installs plugins from Customize > Plugins in three ways: adding a marketplace by GitHub `owner/repo` (also GitHub Enterprise and public GitLab or Bitbucket), uploading a `.zip` or `.plugin` file, or browsing Anthropic's directory on Pro and higher plans; a plugin installed on the account also appears in Claude Code as a synced plugin. — [Plugins](https://claude.com/docs/plugins/overview), accessed 2026-10-21.
- **ENB-14** [grounded] The same plugin folder loads differently by surface: skills load in chat, Cowork and Claude Code, commands load as skills in chat, but plugin agents and hooks are ignored in claude.ai chat, a top-level `bin/` makes chat and Cowork refuse the plugin, and user-added marketplaces are capped at 25 with plugins at 5,000 files and 200 MB. — [Plugin feature support across platforms](https://claude.com/docs/plugins/platform-support), accessed 2026-10-21.
- **ENB-15** [grounded] Claude Code downloads skills enabled on a claude.ai account into `~/.claude/skills/synced/` (download-only) in terminal sessions signed in with that account, from v2.1.273, which was published on September 15, 2026. — [Extend Claude with skills](https://code.claude.com/docs/en/skills); [npm registry: @anthropic-ai/claude-code](https://registry.npmjs.org/@anthropic-ai/claude-code), accessed 2026-10-21.
- **ENB-16** [grounded] Codex reads plugin marketplaces from `.agents/plugins/marketplace.json` and, as a "legacy-compatible" path, from `.claude-plugin/marketplace.json`, adds them with `codex plugin marketplace add owner/repo`, and publishes approved public plugins to one directory shared by ChatGPT and Codex, from which plugins with lifecycle hooks are excluded. — [Build plugins (Codex)](https://developers.openai.com/codex/plugins/build), accessed 2026-10-21.
- **ENB-17** [grounded] Copilot CLI looks for `marketplace.json` in a repository's `.github/plugin` directory and also checks `.claude-plugin/`, and users add a marketplace with `copilot plugin marketplace add owner/repo`. — [Copilot CLI plugin marketplaces](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/plugins-marketplace), accessed 2026-10-21.

## (b) claude.ai Projects, artifacts and web search

- **ENB-18** [grounded] Classic claude.ai Projects, with their own knowledge files, instructions and chat history, are available on every plan, with Free capped at five projects; retrieval that expands project knowledge up to tenfold is paid-only, and sharing is limited to Team and Enterprise. — [What are projects?](https://support.claude.com/en/articles/9517075-what-are-projects), accessed 2026-10-21.
- **ENB-19** [grounded] A redesigned Projects, where one conversation coordinates parallel cloud threads, is in public beta on Pro and Max only (not Team or Enterprise); earlier chat and Cowork projects "keep working as they do today until the redesigned experience reaches them", and cloud threads load account skills but not a repository's `.claude/skills`. — [Let Claude coordinate ongoing work with Projects](https://code.claude.com/docs/en/claude-projects), accessed 2026-10-21.
- **ENB-20** [grounded] A March 5, 2026 Anthropic post says skills work in any conversation and any project, and contrasts Projects as always-loaded background knowledge with skills as procedures loaded only when relevant. — [Skills explained](https://claude.com/blog/skills-explained), accessed 2026-10-21.
- **ENB-21** [grounded] Artifacts are available on every plan once code execution and file creation is on; chat artifacts made before September 16, 2026 are now "legacy" and that kind can no longer be created; Docs export to Word, PDF, Markdown or Google Docs, and artifacts can keep up to 20 MB of text data on paid plans. — [What are artifacts and how do I use them?](https://support.claude.com/en/articles/9487310-what-are-artifacts-and-how-do-i-use-them), accessed 2026-10-21.
- **ENB-22** [grounded] Web search on claude.ai launched on March 20, 2025, as a preview for paid users in the United States, and became available globally on all plans, including Free, on May 27, 2025. — [Claude can now search the web](https://claude.com/blog/web-search), accessed 2026-10-21.
- **ENB-23** [grounded] Research mode, which chains many searches and can read connected tools without per-step approval, is paid-only (Pro, Max, Team, Enterprise), needs web search on, and runs on Claude Opus 5.5 whatever model the chat uses; the help page does not say whether it works inside Projects or can be started by a skill. — [Using Research on Claude](https://support.claude.com/en/articles/11088861-using-research-on-claude), accessed 2026-10-21.

## (c) Claude Code subagents and web tools

- **ENB-24** [grounded] Claude Code subagents run in their own context window with their own prompt and tool list, are defined as Markdown files in `.claude/agents/` or a plugin's `agents/`, run up to 20 at once by default, can nest three levels deep, and draw on the same usage limits as the main session; custom subagents first shipped in v1.0.60, published July 24, 2025. — [Create custom subagents](https://code.claude.com/docs/en/sub-agents); [npm registry: @anthropic-ai/claude-code](https://registry.npmjs.org/@anthropic-ai/claude-code), accessed 2026-10-21.
- **ENB-25** [grounded] Claude Code's WebSearch returns titles and URLs only, from Anthropic's backend, with a limit of 200 calls per interactive session shared with subagents and no support on Amazon Bedrock; WebFetch passes each page through a separate model call (lossy by design), reads up to 100,000 characters per call, asks before each fetch in the default permission mode unless the domain is allowed or preapproved, and identifies itself with a `Claude-User` user agent. — [Tools reference](https://code.claude.com/docs/en/tools-reference), accessed 2026-10-21.
- **ENB-26** [grounded] Claude Code ships a built-in `/deep-research` workflow that fans out web searches, cross-checks and votes on claims, and returns a cited report; workflows are on all paid plans (opt-in on Pro), and runs over 25 agents or 1.5 million projected tokens show a cost warning. — [Orchestrate subagents at scale with dynamic workflows](https://code.claude.com/docs/en/workflows), accessed 2026-10-21.

## (a, e) Claude API: skills and web tools

- **ENB-27** [grounded] On the API, skills require the code execution tool, are managed through `/v1/skills` and shared workspace-wide, run in a container with no network access and no runtime package installs, are not covered by zero data retention, and may not use "anthropic" or "claude" in their names. — [Agent Skills (Claude Platform docs)](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview), accessed 2026-10-21.
- **ENB-28** [grounded] The API web search tool costs $10 per 1,000 searches plus tokens, always returns citations, and has three versions (March 2025 basic, February 2026 with code-based filtering, March 2026 with response control), but is not available on Amazon Bedrock; the companion web fetch tool has no extra fee, may only fetch URLs that already appeared in the conversation, and refuses URLs disallowed by `robots.txt`. — [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool); [Web fetch tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-fetch-tool), accessed 2026-10-21.

## (d) Equivalents in other ecosystems

- **ENB-29** [grounded] ChatGPT projects group chats, files, instructions and sources; web projects cannot reach a local folder, while desktop-app local projects connect to folders and discover skills from the primary folder, and plugins work in ChatGPT Work. — [Projects and chats](https://learn.chatgpt.com/docs/projects), accessed 2026-10-21.
- **ENB-30** [grounded] OpenAI is retiring custom GPTs in favour of plugins, with skills taking over a GPT's instructions and reference files and custom actions needing a rebuild as connectors or MCP servers; the page gives no retirement date. — [Moving custom GPT workflows to plugins](https://learn.chatgpt.com/docs/migrate-custom-gpts), accessed 2026-10-21.
- **ENB-31** [grounded] Copilot Spaces are shareable collections of repositories, code, pull requests, issues, notes and uploaded files, usable with any Copilot license including Free and reachable from IDEs through the GitHub MCP server; the page does not say whether skills or agents run inside a space. — [About Copilot Spaces](https://docs.github.com/en/copilot/concepts/context/spaces), accessed 2026-10-21.
- **ENB-32** [grounded] Gemini skills can be imported by uploading `SKILL.md` files made on other platforms (Mac and web apps only for now), but do not work with Canvas or Deep Research, cap active skills at 100, and are currently open to people over 18 on personal Google accounts, with work and school accounts expected later; personal-account Gems are removed in November 2026 and converted to skills. — [About the transition from Gems to skills](https://support.google.com/gemini/answer/18560919?hl=en), accessed 2026-10-21.

## (e) Deep-research APIs elsewhere

- **ENB-33** [grounded] OpenAI's `o3-deep-research` and `o4-mini-deep-research` API models, which run for up to tens of minutes, were deprecated on April 22, 2026, and shut down on July 23, 2026, with `gpt-5.6-sol` named as the replacement; their background mode is incompatible with zero data retention. — [Deep research (OpenAI API)](https://developers.openai.com/api/docs/guides/deep-research), accessed 2026-10-21.
- **ENB-34** [grounded] Google's Gemini Deep Research agent is in preview, callable only through the Interactions API in background mode (agent IDs `deep-research-preview-04-2026` and `deep-research-max-preview-04-2026`), takes several minutes, and returns cited reports using Google Search, URL context and code execution by default. — [Gemini Deep Research agent](https://ai.google.dev/gemini-api/docs/deep-research), accessed 2026-10-21.

## (f) Web access terms

- **ENB-35** [grounded] Anthropic's `Claude-User` agent fetches pages when a user asks; Anthropic's bots honour `robots.txt` and Crawl-delay and do not bypass CAPTCHAs, and a site that blocks `Claude-User` is not retrieved for user queries (page updated April 7, 2026). — [Does Anthropic crawl data from the web?](https://support.claude.com/en/articles/8896518-does-anthropic-crawl-data-from-the-web-and-how-can-site-owners-block-the-crawler), accessed 2026-10-21.

## Notes for frame

_Judgment, not evidence._

- Timing: almost every piece the idea needs landed between October 2025 and October 2026: skills (ENB-01), plugins (ENB-12), the open standard and its uptake by Codex, Copilot and Gemini (ENB-04, ENB-06, ENB-07), claude.ai installing plugins from a GitHub marketplace (ENB-13), and claude.ai-to-Claude Code skill sync (ENB-15).
- Feasibility of the dual path: chat ignores plugin agents (ENB-14), which supports the paste-in prompt design for the challenge in chat, and skills reach Projects (ENB-20). Claude Code-only frontmatter would block a claude.ai upload (ENB-11), so the chat package probably needs spec-only frontmatter.
- Platform churn is high: classic Projects are being replaced (ENB-19), legacy artifacts are frozen (ENB-21), Gems and custom GPTs are being retired (ENB-30, ENB-32), and OpenAI shut down its deep-research API models (ENB-33). Anthropic's own docs disagree on Free-plan skills (ENB-08) and on skill sharing and sync (ENB-10 against ENB-09 and ENB-15).
- Plan gating: chat web search is on every plan (ENB-22), but skills need code execution and Free access is ambiguous (ENB-08), Research is paid-only (ENB-23), and the new Projects is Pro and Max only (ENB-19).
- Substitution: the built-in `/deep-research` (ENB-26) and Research mode (ENB-23) already cover generic cited research, so the scout step may differ more in structure (lanes, ledger, lenses) than in search capability.
- Portability looks cheap at the format level: Copilot and Codex read `.claude-plugin` marketplaces (ENB-16, ENB-17) and Copilot reads `.claude/skills` (ENB-06). Codex calls that path legacy, though, so the compatibility may not last.
