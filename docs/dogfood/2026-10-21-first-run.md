run found with what the session had concluded, and lists what changed in the

## What the run corrected in our own conversation

The transcript doubles as a fixture: these are claims the design session made
that the run then checked.

1. **"Nothing asks has this been done."** True inside the pegboard, false
   outside it. GitHub Spec Kit shipped a first-party `assess` extension in July
   2026, BMAD has an explore-and-validate step, and idea-validation repos went
   from 115 in 2025 to 542 this year (`LND-14` to `LND-16`).
2. **"AI assistants are enthusiastic."** Documented in general, but Claude's
   measured rate is low: 9% of guidance conversations, 18% under pushback
   (`DEM-16`, `DEM-17`).
3. **"Codex and Copilot may lack a chat project."** Partly wrong. ChatGPT
   Projects run skills on desktop and the Gemini app adopted skills; whether
   Copilot Spaces run skills is still unknown (`ENB-05`, `ENB-07`, `ENB-31`).
4. **"claude.ai skills are a separate zip upload."** Out of date. claude.ai
   now installs plugins from a GitHub marketplace and syncs them to Claude
   Code (`ENB-13`, `ENB-15`). The session relied on a search snippet; the
   lane opened the page.
5. **"assay" as the favourite name.** Crowded, with an agent QA tool of the
   same name. Eight of seventeen workshop names already label agent or
   spec-driven tools.
6. **The posture as a wedge.** It holds up, but narrower than framed: BMAD has
   a defend mode and one pack leads with the best case (`S-02`, `S-05`). It
   has to be written as behaviours, not tone (`V-04`).
7. **The goal for the tool itself** was never stated. Capture recorded it as
   unstated instead of guessing, and every Monetizable reading branches on it.

## What the pack got wrong, and the change made

| Problem | Found by | Change |
|---|---|---|
| Every skill carried `user-invocable`, which claude.ai uploads reject | enablers lane, skeptic, rival | Spec-only frontmatter; a check confirms all seven pass |
| Merging lane entries into fresh `E-NN` IDs was busywork and risked errors | the merge step | Source-prefixed IDs (`LND`, `DEM`, …); the dossier keeps an index |
| Nobody searched for the claimed difference | skeptic | Scout searches for it and records an absence with searches |
| Gaps were measured against one rival | skeptic | Scout and frame name the closest rival per gap |
| A quote lost its qualifier in the Open reading | skeptic | Evidence rules: quotes must match their source, qualifiers included |
| The dossier buried its readings on line 266 | customer | An "At a glance" block on top, refreshed by verdict |
| A full scout costs about a million tokens | the run | Light and full depths; light is the default in chat |
| Chat export would mean copying seven files | customer | In chat, the whole dossier stays in one artifact |
| Skills fire on about half of prompts | customer | A one-line Project instruction in the README |
| The user's past projects had no home in scout | the run | The user's own record as a sixth source, tagged `OWN` |
| Three hats raised one issue from three sides | assembling the round | Challenge groups concerns by the risk they land on |
| Handoff had no path for a pending decision | the run | A draft mode with a banner naming the assumed call |
| The naming brief had no question on collision tolerance | name | Added, with the family's precedent as an example |

What worked as designed: capture's no-inference rule; "not looked at" kept
apart from "fine"; the hats' five-concern cap and "what holds up" first; all
three hats covered all six lenses and stayed constructive; proposed
dispositions left the readings untouched.

## Not tested

- The chat path: plugin install from a GitHub marketplace, the Project
  instruction, the paste-in challenge prompts, and moving a dossier to a repo.
- Automatic triggering: every skill was loaded by hand.
- `verdict` recording a real decision, since the decision is pending.
- Whether skills can read `skills/_shared/` from inside a plugin in claude.ai.
- Codex and Copilot.

## Suggested edits to PITCH.md

The pitch makes two claims this run contradicted. Suggested replacements,
ready to paste:

- For the paragraph starting "AI assistants make this worse":

  > AI assistants are agreeable by design, and an idea discussed in chat
  > rarely leaves with sources you can click. Tools that ask the hard
  > questions do exist, such as GitHub Spec Kit's assess extension, BMAD's
  > Forge Idea, and a fast-growing set of idea-validation skills. Most of them
  > need a terminal and a repository, and most lead with a kill verdict.

- After the first paragraph of "The idea", add:

  > What it adds: it starts in a chat Project before any repository exists;
  > it is encouraging by default, with a challenge only on request; every
  > claim is sourced, dated and link-checked; and the dossier moves into the
  > repository with the build.

- Add a sixth question: "Where do you start a new idea, in chat or in a
  repository? Do you use a coding agent in a terminal?"

## Follow-up, same day: slimmed to a thin layer

Julien's direction after reading the run: reuse existing tools where possible,
no framework packs, and stay "lean and complementary to the rest of the tools
in the ai-pegboard project". A check of the closest pieces found none that
both stands alone and covers the job (`LND-36` to `LND-40`). So the pack
reuses capabilities, not packs.

| Before | After |
|---|---|
| Scout fanned out five research subagents, about a million tokens | Scout drafts a research brief per lane (`templates/research-brief.md`) for Research mode, `/deep-research`, or any tool, then processes the report: extract, check links, file, note gaps. A quick pass of a few searches remains for small questions. |
| A separate `verdict` skill | Folded into `frame`: "where you stand" refreshes the At a glance block, and the decision is recorded there |
| The challenge always used its own three hats | The challenge offers an installed grilling skill first, briefed with the dossier and the three angles; the independent hats remain the fallback |
| Seven skills | Six: capture, scout, frame, challenge, name, handoff |

The draft-then-process research flow is borrowed as a pattern from BMAD's
Deep Recon, with no dependency on BMAD. Reports from research tools now count
as `unverified` until their sources are opened.

The pitch should say this too. Add to the suggested "What it adds" paragraph:
"It uses the research and grilling tools you already have, and adds the
dossier, the lenses, and the handoff."
